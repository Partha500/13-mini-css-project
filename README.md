## ✨ Features

- **Pure CSS Interactive Toggle**: Operates dynamically using the CSS `:checked` pseudo-class selector without relying on JavaScript.
- **Glassmorphism Visual Style**: Semi-transparent sidebar panel with subtle box-shadows and backdrop visual depth.
- **Responsive Navigation**: Hamburger icon toggle to slide out the sidebar smoothly across different viewport sizes.
- **Iconography & Typography**: Integrated with Google Fonts (*Outfit*) and Font Awesome v6 icons for clean visual cues.
- **Micro-Interactions**: Smooth scale transforms, hover state shadows, and opacity transitions on navigation links and social icons.
